# 记录中心 · GitHub 部署包

单文件 PWA 工具箱，数据全部只存在本机浏览器（localStorage），不上传任何服务器。含医院流向、客户产出、资源投入等 13 个模块。

## 已含模块
- **医院流向**（含「录入 / 汇总 / 趋势 / **进销存** / **流水**」五个页签）
- **客户产出**（含「投入 N」徽标联动）
- **资源投入**（独立模块）
- 日均账本、元UP能耗、哨兵耗电、充电日历、排便日历、经期助手、元UP充电、医院客户管理、科室会/学术会、记账本、备份与恢复

## 进销存（库存）用法
1. 打开「医院流向」→「进销存」页签。
2. 点「新增产品/医院」录入院/产品（可多条）。
3. 【期初库存】首次使用或中途接手时，在录入区「期初库存」填一个数、点「设期初」，即可把现有库存记进去（剩余 = 期初 + 进货 − 销量）。
4. 每天/每周在顶部「进货」「销量」切换，输入数量后保存。
5. 系统按「期初 + 进货 − 销量」实时计算每院每产品剩余库存；「警戒值」列设下限，低于下限自动标红 ⚠。
6. 「流水」页签按全部/进货/销量/本月/本周筛选，支持删除（删除后自动重算库存）。
7. 首页「医院流向」卡片会显示「在库 N 品种 / 低于警戒 M」概览。

## 资源投入用法
1. 打开「资源投入」→「录入」页签，填写医院/客户、类型、金额、日期。
2. 支持「复制上一条」快速续录；类型自动记忆进下拉。
3. 「明细」可按本周/本月/类型筛选；「汇总」按医院/客户/类型统计并支持导出 Excel。
4. 在「客户产出 → 设置」页，有投入记录的医院/客户会显示「💰投入 N」徽标。
5. **改名自动同步**：在「客户产出 → 设置」里给医院/客户改名或合并时，资源投入里的同名记录会自动跟随改名，徽标不丢失。
6. 在「客户产出」里新增医院/客户后，切到「资源投入」录入页，医院/客户下拉会**实时刷新**，无需重进。

## 部署到 GitHub Pages
1. 在 GitHub 新建仓库（如 `record-center`）。
2. 把本目录全部内容（`index.html`、`sw.js`、`manifest.webmanifest`、`icons/`、`.nojekyll`）推到仓库。
3. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存。
4. 约 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/` 即可。
5. 手机浏览器打开后可「添加到主屏幕」当作 App 使用（离线也能开）。

> Service Worker 缓存版本号：`record-center-20260913`，后续大改时改 `sw.js` 里的 `CACHE` 即可强制更新。
